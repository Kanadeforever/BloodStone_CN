# BloodStoneCN ASI 三目录保底补丁——使用说明

本工具在 EXE 入口主动加载 ASI，不依赖 Ultimate ASI Loader 代理 DLL。已实机验收的是早期双 ASI 入口方案；三目录扫描扩展仍需实际游戏验证。

## 一、准备 Python 便携运行时 (已经准备好了，可以跳过本步骤)

下载官方 **Python 3.12.10 Windows embeddable package (32-bit)**：

https://www.python.org/ftp/python/3.12.10/python-3.12.10-embed-win32.zip

**打开这个 ZIP，把其中全部文件直接解压到：**

`release\runtime\python\`

**不要把 ZIP 解压成 `python-3.12.10-embed-win32` 子文件夹。** 正确结构：

```text
release\
├─ 运行补丁.bat
├─ pe_asi_patch.py
├─ 放入Bond.exe\
└─ runtime\
   └─ python\
      ├─ python.exe
      ├─ python3.dll
      ├─ python312.dll
      ├─ python312.zip
      ├─ python312._pth
      └─ 其他 ZIP 自带文件
```

官方 Python ZIP 内的文件解压原样保留，不需要安装 Python，不需要 pip，不需要修改 `_pth` 文件。此步骤由**制作发行包的人执行一次**。准备好以后把整个包分发给玩家，玩家不需要联网或安装 Python。

**当前交付物不包含官方 Python 二进制。** 只有完成上述手动放置后，才算完整离线发行包。工具运行时不会联网，也不会尝试调用系统 Python。

## 二、生成补丁

1. 将已经脱壳的游戏 `Bond.exe` 复制到 `release\放入Bond.exe\`。保留未修改的原版备份。
2. 双击 `release\运行补丁.bat`，它会调用 `release\runtime\python\python.exe`。
3. 成功后，同一文件夹生成 `Bond.asi-auto.exe`，原始 `Bond.exe` 不变。若输出已存在，工具会拒绝覆盖。
4. 按任意键结束 CMD，工具会自动打开 `release\放入Bond.exe\` 文件夹。
5. 备份游戏目录中的原始 `Bond.exe`，再把输出的 `Bond.asi-auto.exe` 放回游戏目录并改名为 `Bond.exe`。

**原版带壳 EXE 不一定能直接打补丁**。当前只在用户提供的两份脱壳分析版 EXE 上做过结构测试。游戏目录以及原有汉化资源目录不需要重排。

## 三、游戏 ASI 扫描规则

游戏入口先尝试加载 `CN_Data\BloodstoneCN.asi`、`CN_Data\NPCSubtitles.asi`，之后依次扫描三个目录直属的 `.asi` 文件：

```text
游戏目录\
├─ Bond.exe
├─ scripts\*.asi
├─ CN_Data\*.asi
└─ plugins\*.asi
```

目录内枚举顺序由 Windows 决定，无法保证任意第三方插件之间的初始化顺序。已加载的插件不重复加载。单个插件装载失败时记录错误并跳过；插件自身初始化崩溃仍可能导致游戏退出。

装载日志位于游戏目录 `BloodStoneASI加载日志.txt`，不是补丁工具目录。

## 四、故障提示

- 缺少便携 Python：核对 `python.exe` 和 `python312.dll` 等文件是否直接位于 `release\runtime\python\`。
- CMD 提示运行时无法启动：检查 Python 是否完整解压，或系统是否缺少其运行依赖。不要只复制 `python.exe`。
- 补丁提示不支持：检查输入是否为脱壳 Windows x86 PE32，以及是否为已经打过补丁的文件。
- 游戏没有汉化：查看游戏目录的 `BloodStoneASI加载日志.txt`，确认相应 ASI 是否装载成功。

本包不执行下载、不使用 PowerShell，也不修改游戏原始资源或 ASI 文件。
