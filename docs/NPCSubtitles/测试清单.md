# NPCSubtitles 0.2.2 D3D9InteropSafe 测试清单

## A. 0.2.1 启动 Hook 回归 —— 首要检查

- [ ] 游戏正常启动，不崩溃。
- [ ] 日志出现 `NPC_SUBTITLE_D3D9_BOOTSTRAP_BEGIN`。
- [ ] 日志出现 `NPC_SUBTITLE_CREATE_DEVICE_HOOK_OK source=bootstrap` 或 `source=iat`。
- [ ] 日志出现 `NPC_SUBTITLE_RESET_HOOK_OK`。
- [ ] 日志出现 `NPC_SUBTITLE_ENDSCENE_HOOK_OK`。
- [ ] 日志出现 `NPC_SUBTITLE_D3D9_BOOTSTRAP_OK`；若 bootstrap 失败但后续 `source=iat` 成功，也记录完整日志。
- [ ] 日志出现 `NPC_SUBTITLE_ENDSCENE_ACTIVE viewport=...`。
- [ ] 第一次中文字幕绘制前后出现 `BFA_GPU_OK`。
- [ ] 0.1 已经成功的 NPC 字幕重新正常显示。
- [ ] 中文环境仍为 `selected=CHINESE_BSCN`。
- [ ] 英文 fallback 环境仍为 `selected=ENGLISH_NATIVE_FALLBACK`。
- [ ] 原游戏自身剧情字幕、菜单、主汉化显示不受影响。

## B. 布局

- [ ] 单行字幕位置比 0.1 略高。
- [ ] 自动换成双行时，两行间距明显小于 0.1。
- [ ] 两行不存在字形重叠。
- [ ] 720p 与更高分辨率下相对位置/间距观感一致。

默认参数：

```ini
BaseY=0.120
LineSpacing=0.82
```

## C. 分辨率切换 —— 本版最高优先级

1. 启动游戏并触发字幕；
2. 进入设置改变分辨率；
3. 等画面恢复；
4. 再触发 NPC 对话。

必须确认：

- [ ] 有 `NPC_SUBTITLE_RESET_HOOK_OK`；
- [ ] 切分辨率时有 `NPC_SUBTITLE_DEVICE_RESET_BEGIN`；
- [ ] Reset 成功时有 `NPC_SUBTITLE_DEVICE_RESET_OK`；
- [ ] 随后有 `NPC_SUBTITLE_POST_RESET_DRAW_OK`，确认 EndScene 在 Reset 后仍然活跃；
- [ ] `viewport=` 与切换后的分辨率一致或符合游戏实际 backbuffer；
- [ ] 中文模式 `chinese_texture=1`；
- [ ] 改分辨率后 NPC 字幕继续显示。

如果失败，完整保留 `NPCSubtitles.log`，不要只截最后几行。

## D. 多次切换

- [ ] 720p → 1080p → 720p 连续切换仍能显示；
- [ ] 若游戏支持窗口/全屏模式变化，同样测试一次；
- [ ] Alt+Tab 后再触发字幕不新增异常；
- [ ] 游戏退出正常。

## E. 英文 fallback Reset

- [ ] Reset 前英文字幕正常；
- [ ] Reset 时出现 `NPC_NATIVE_FONT_GPU_INVALIDATED`；
- [ ] Reset 后游戏重新使用字体时可以重新捕获有效原生纹理；
- [ ] 若短时间出现 `NPC_NATIVE_FONT_WAIT`，随后应恢复；若一直 WAIT，提交完整日志。

## 0.2.2 首轮实机测试 —— 先验收主汉化不再被污染

### A. 版权页 / 主汉化完整性

同时加载：

```text
BloodstoneCN.asi
NPCSubtitles.asi 0.2.2
```

必须确认：

- 版权页不再出现 0.2.1 截图中的碎裂/错贴纹理；
- 主菜单及其它中文保持 0.1 时的正常效果；
- BloodstoneCN 的 `BFA_GPU_OK` 必须来自 Bond 的真实 Device 路径，不能因为 NPC 的 dummy bootstrap 被提前触发。

### B. NPCSubtitles 启动日志

优先期待：

```text
NPC_SUBTITLE_RENDERER_EARLY_INSTALL ... before_dialogue_index=1
NPC_SUBTITLE_D3D9_IAT_HOOK_OK
NPC_SUBTITLE_D3D9_BOOTSTRAP_BEGIN ... INTEROP_SAFE_RAW_EXPORT
NPC_SUBTITLE_D3D9_BOOTSTRAP_CREATEDEVICE_CLEAN owner=d3d9.dll chain_bypass=1
NPC_SUBTITLE_RESET_HOOK_OK
NPC_SUBTITLE_ENDSCENE_HOOK_OK
NPC_SUBTITLE_D3D9_BOOTSTRAP_OK ... create_hook_side_effect=0
NPC_SUBTITLE_ENDSCENE_ACTIVE viewport=...
```

如果出现：

```text
NPC_SUBTITLE_D3D9_BOOTSTRAP_SKIP_FOREIGN_CREATEDEVICE ... no_dummy_device=1
```

先不要判失败。继续看真实游戏是否随后走 IAT/CreateDevice，并最终出现 `NPC_SUBTITLE_ENDSCENE_ACTIVE`。

### C. NPC 中文字幕

必须继续看到：

```text
NPC_DIALOGUE_EVENT ... index=HIT allowed=1
NPC_SUBTITLE_QUEUE ... mode=CHINESE_BSCN
```

并在画面上正常显示。

### D. 分辨率切换

只有 A/B/C 全部成立后，再测试 0.2 原始目标：切换分辨率后仍出现：

```text
NPC_SUBTITLE_DEVICE_RESET_BEGIN
NPC_SUBTITLE_DEVICE_RESET_OK ... chinese_texture=1
NPC_SUBTITLE_POST_RESET_DRAW_OK viewport=...
```

并确认字幕继续显示。
