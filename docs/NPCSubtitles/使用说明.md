# NPCSubtitles 0.2.2 D3D9InteropSafe 使用说明

## 作用

这是独立的 NPC / 场景对白字幕插件，不属于 `BloodstoneCN.asi` 主汉化本体。

正式文件：

```text
scripts\NPCSubtitles.asi
scripts\NPCSubtitles.ini
scripts\NPCSubtitles.log
```

## 0.2 相对 0.1 的实机反馈修复

0.1 已经由用户实机确认字幕显示效果成立，整体效果超出预期。当前确认的三个问题为：

1. 自动换成双行时，两行之间间距过大；
2. 字幕整体相对位置略低；
3. **切换/改变游戏分辨率后字幕完全不再显示**。

0.2 优先修复第 3 项，同时调整前两项：

- 新增 D3D9 `IDirect3DDevice9::Reset [16]` 生命周期 Hook；
- Reset 前释放 NPCSubtitles 自己的中文 BFA GPU 纹理；
- Reset 成功后立即按新 device/viewport 重建 BFA GPU 纹理；
- 英文 fallback 在 Reset 前清空可能已经失效的游戏原生纹理指针缓存；
- `BaseY` 默认从 `0.145` 改为 `0.120`，字幕向上移动；
- 新增 `LineSpacing=0.82`，双行间距明显收紧；
- 多个同时存在的字幕事件之间的垂直步进也同步收紧。

## 两种自动模式

默认：

```ini
[Resources]
Mode=Auto
```

当以下三个条件全部成立时进入中文模式：

```text
scripts\BSCNContents\fonts.bfa       有效 BSCNATL1
scripts\BSCNContents\loc_context.bli 有效 BSCNLI3 v3
scripts\BSCNContents\loc\            存在
```

否则进入 `ENGLISH_NATIVE_FALLBACK`。英文模式不需要 `BloodstoneCN.asi`，也不要求 BFA/BLI/LOC。

## 显示参数

```ini
[Display]
Scale=0.56
BaseY=0.120
MaxWidth=0.66
LineSpacing=0.82
MaxVisibleLines=3
```

其中：

- `BaseY` 越小，字幕越靠上；如果仍略低，可试 `0.110`；
- `LineSpacing` 越小，自动换行后的两行越紧；建议先在 `0.75 ~ 0.90` 范围微调；
- `Scale` 和 `MaxWidth` 沿用 0.1 的成功基线，不在本轮扩大变量。

## 本轮必须测试

先正常触发一条字幕，确认可见；然后在游戏设置中改变分辨率，等画面恢复后再次触发 NPC 对话。

日志应出现：

```text
NPC_SUBTITLE_RESET_HOOK_OK
NPC_SUBTITLE_DEVICE_RESET_BEGIN request=<宽>x<高> ...
NPC_SUBTITLE_DEVICE_RESET_OK mode=... viewport=<宽>x<高>
NPC_SUBTITLE_POST_RESET_DRAW_OK viewport=<宽>x<高>
```

中文模式的成功 Reset 日志还应有：

```text
chinese_texture=1
```

如果改变分辨率后字幕仍不显示，不要继续猜地址，直接保留完整 `NPCSubtitles.log`；0.2 的 Reset 日志已经能够区分 Reset 没被调用、Reset 失败、viewport 未恢复、BFA GPU 纹理重建失败等情况。

## 重要限制

- 战斗喊话字幕继续封存。
- 不恢复旧 `SubmitText 0x00E85900` NPC 创建路线。
- 不要同时加载旧 `zzzz_BloodstoneNpcSubtitles.asi`、Dialogue Probe 或 R10.1~R10.3 NPC 主程序集成测试版。

## 0.2.2 与 BloodstoneCN 共存修复

0.2.1 的 `D3D9Bootstrap` 首轮实机暴露出严重互操作问题：它通过 `previous_d3d9_` / `previous_create_` 创建 8×8 临时 Device。若 `BloodstoneCN.asi` 已经位于 IAT/CreateDevice chain 中，这个临时 Device 会穿过 BloodstoneCN 的 D3D9 Hook，导致主汉化误把 NPCSubtitles 的临时 Device 当成 Bond 的真实 Device，并在临时 Device 上建立 BFA GPU 纹理。

0.2.2 改为：

1. 在昂贵的 22 个 NPC LOC 索引扫描之前安装 NPCSubtitles 的 D3D9 Hook；
2. late bootstrap 不再调用 `previous_d3d9_`、不再调用 `previous_create_`、不再给临时 `IDirect3D9` 安装 CreateDevice Hook；
3. bootstrap 直接从已加载的 `d3d9.dll` 取得原始 `Direct3DCreate9` export；
4. 只有 `IDirect3D9::CreateDevice` 当前 owner 仍然属于 `d3d9.dll` 时，才允许创建 8×8 临时 Device；
5. 若 CreateDevice 已被任何其它模块接管，bootstrap **安全放弃**，只保留 IAT future-call 路线，绝不再让临时 Device 穿过其它 ASI 的 CreateDevice chain；
6. 临时 Device 只用于取得共享 `IDirect3DDevice9` vtable，并补装 `Reset [16]` / `EndScene [42]`，不会触发 BloodstoneCN 的字体资源初始化。

本版本仍保留 0.2 的：

```ini
BaseY=0.120
LineSpacing=0.82
```

以及完整 Reset 生命周期修复。
