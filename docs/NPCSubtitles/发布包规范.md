# NPCSubtitles 0.2 发布包规范

正式运行内容：

```text
scripts\NPCSubtitles.asi
scripts\NPCSubtitles.ini
```

运行时自动生成：

```text
scripts\NPCSubtitles.log
```

若作为 BloodstoneCN 中文整合包发布，中文资源仍由外部目录提供：

```text
scripts\BSCNContents\fonts.bfa
scripts\BSCNContents\loc_context.bli
scripts\BSCNContents\loc\...
```

NPCSubtitles 自身不得把 BFA/BLI/LOC 或整套英文 NPC 句子编译进 ASI。

每个源码包、编译内容包都必须带一份**截至该版本的完整接档 Markdown**，内容至少包括：已确认架构、地址/ABI、成功方案、失败方案、实机结论、踩坑、当前阻塞项、下一步和本版本变更。不能只附本轮 changelog。

建议源码包至少包含：

```text
src\
config\NPCSubtitles.ini
build_msvc_x86.bat
CMakeLists.txt
完整接档.md
使用说明.md
技术说明.md
测试清单.md
已知问题与下一步.md
编译说明.md
发布包规范.md
版本信息.txt
测试结果.txt
源码验证.json
```
