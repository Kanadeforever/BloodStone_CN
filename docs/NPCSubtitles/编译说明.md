# 编译说明

目标是 **Win32/x86**，因为 `Bond.exe` 是 32 位程序。

最简单的方法：双击项目根目录的：

```text
build_msvc_x86.bat
```

脚本使用 Visual Studio 的 CMake，明确配置 `-A Win32`，不使用 Ninja。

成功后产物：

```text
release\NPCSubtitles.asi
release\NPCSubtitles.ini
```

若 CMake 提示 64 位，删除 `build\msvc-x86` 后重新运行脚本。源码中同时有 `static_assert(sizeof(void*)==4)`，错误位数不会悄悄生成不可用 DLL。

本包在当前 Linux 生成环境无法进行真实 Windows SDK/MSVC 链接，因此这里提供的是**经过源码静态检查和 Python 合约测试的可编译源码**，最终 PE32 仍以你本机 MSVC 编译结果为准。
