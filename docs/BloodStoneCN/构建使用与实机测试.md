# R10.4 W1.2b 构建、部署与实机测试

## 0. 本轮先验收中文覆盖回滚

W1.2a 已实机失败，测试 W1.2b 时第一优先级不是混杂，而是确认 W1.1 已正常的中文全部恢复：

- 关卡选择界面；
- 任务说明；
- 城市/地点；
- Mission Updated / Objective；
- 教程、动作提示、Focus Aim；
- 剧情字幕。

然后再确认：

- P99/MP7/MP5 等换枪仍正常；
- 弹药逐发更新、换弹、切枪正常；
- 中文字体无口口口；
- 关卡选择 FPS 是否因默认关闭高频诊断而恢复。

默认配置必须保持 `LogMisses=0 / LogActionTokens=0 / LifecycleProbe=0` 做性能验收。

---

## 0.1 字体链仍是硬门禁

W1.1 编译后第一次运行，日志必须先满足：

```text
R10_4_W1_2b_EARLY_D3D_READY ... BEFORE_LOC_BLI_COVERAGE_PARSE
D3D9 CreateDevice hook installed
BFA_GPU_OK
FONT_GATE_READY localization_output=ENABLED
...
UNICODE_LOC_HOOK_OK
SUBMIT_TEXT_HOOK_OK
Initialization state ... font_render_ready=1
```

若 `BFA_CPU_OK` 存在但没有 `BFA_GPU_OK/FONT_GATE_READY`，不要继续评价枪械实验；说明 D3D 字体链仍未闭合。

如果字体 gate 在 Reset 窗口关闭，允许看到：

```text
FONT_GATE_SKIP_SUBMIT action=KEEP_ORIGINAL until=ATLAS_READY
```

它只应是短暂安全保护，Reset 后应再次出现 `FONT_GATE_READY`。

## 1. 构建

目标必须是 Win32 / x86 / PE32。

在 Windows 上运行：

```bat
构建_MSVC_x86.bat
```

本修正版已经修复 `%~dp0` 末尾反斜杠导致 CMake 将 `-B/-A` 误吞进 `-S` 参数的问题。启动时应先看到类似：

```text
[信息] 源码目录：C:\...\BloodstoneCN_R10.4_W1_...
[信息] 构建目录：C:\...\BloodstoneCN_R10.4_W1_...\build
```

随后 CMake 命令中的 `-S`、`-B`、`-A Win32` 应作为三个独立参数解析。

构建后再运行：

```text
python tools\verify_pe.py <生成的 BloodstoneCN.asi>
```

当前交付环境未执行 MSVC Win32 链接，因此本包提供的是已完成静态验证的源码，不伪造 ASI。

## 2. 运行资产

沿用当前 R10.4 已验证的部署资产，不把翻译数据编入 ASI：

```text
scripts\BloodstoneCN.asi
scripts\BloodstoneCN.ini
scripts\BSCNContents\fonts.bfa
scripts\BSCNContents\loc_context.bli
scripts\BSCNContents\loc\...  ; 86 LOC
```

W1 不包含用户已有翻译数据副本，避免污染/重复。

## 3. 首轮测试隔离

建议：

- W1 BloodstoneCN：加载；
- GamepadIcons 1.4.20：可保持；
- NPCSubtitles：首轮先不加载。

## 4. 必测 HUD

反复做：换枪 → 开火 → 换弹 → 再换枪 → 捡起另一把枪。

至少观察：

- Silenced P99 / P99；
- MP7；
- 当前关卡可拿到的 UMP / M1 / Combat A.R. 等；
- 武器名与图标是否同步；
- 当前弹匣数字逐发下降；
- reload 后恢复；
- 换枪后立刻切成新武器的弹药值；
- 拾取提示名称与 HUD 名称一致。

## 5. 中文非回归

必须同时检查：

- 城市名；
- Mission Failed / Objective / Mission Updated；
- Focus Aim；
- 动作提示和控制 token；
- 已正常剧情字幕；
- `消音P99` 不得回退 `Silenced P99`。

## 7. 成败标准

PASS 候选：武器/弹药恢复，同时 R10.4 已正常中文不回归。

FAIL：任何稳定中文大面积重新出现英语，或 HUD 更严重错乱/崩溃。
