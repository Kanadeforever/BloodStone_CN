# 随包工具说明

## 1. `tools/验证源码.py`

用途：验证 W1.2b 源码契约、模型测试、冻结模块 SHA-256、文档目录规范和字库工具完整性。

运行：

```text
python tools\验证源码.py
```

结果会写到：

```text
docs\源码验证结果.txt
```

它不是 Windows PE 链接验证器；真正 ASI 编译后仍需 `tools/verify_pe.py`。

## 2. `tools/verify_pe.py`

用途：检查生成物是否为预期 PE32/i386 DLL/ASI，避免误编 x64。

## 3. `tools/字库重建工具_v1.3`

这是当前项目冻结的“中日文字库重建工具 v1.3（保持原目录结构）”功能文件精简副本。没有随包提供字体文件。

目录：

```text
tools\字库重建工具_v1.3\
├─ font_source\
├─ tools\
│  ├─ font_atlas_tool.py
│  ├─ JSON字符统计工具.py
│  ├─ 验证工具.py
│  └─ requirements.txt
├─ 安装依赖.bat
├─ 扫描JSON字符.bat
└─ 重建字体.bat
```

主要原则：

- 每次全量重建 BFA，不在旧 BFA 后追加；
- 递归扫描 `font_source` 的 TTF/OTF/TTC/OTC；
- 中文模式扫描 JSON，日文模式只读取已识别日文字段；
- 保留可支持 Unicode 标点和 U+3000；
- 生成 Grid074 2048×2048 兼容字体；
- 不改变 W1 本轮 HUD 修复代码。

需要使用时先把用户自己的字体放入 `font_source`，再执行 `安装依赖.bat` / `扫描JSON字符.bat` / `重建字体.bat`。
