# NPCSubtitles v0.1e-log9：安装、诊断与回退

## 安装

将当前发行包的 `release/NPCSubtitles.asi` 放到原有 ASI 目录，替换旧文件即可。游戏原版 `Bond.exe`、PAK 及其他 MOD 不修改。插件从自己的目录访问 `BSCNContents/loc` 和 `BSCNContents/fonts`，不假设 ASI 一定在 `scripts` 或 `plugins`。无需任何 INI、TSV、BFA 或 BLI 文件。

## 字幕功能

- 游戏自身已经显示的剧情对白保留原生 UI，不重复外挂。
- 无原生字幕的 NPC 环境对白由外挂读取中文 LOC 并显示。
- 四条人工确认需要补出的过场台词，允许在过场期间显示。已移除六条名单参阅《过场遗漏台词白名单与测试说明.md》。
- 普通 NPC 进入过场自动清空，过场结束不恢复旧字幕。最多三行，最多三条活动字幕，十六条等待 FIFO。
- 字幕默认无黑底，中英文同高，随 640×480～4K 分辨率自动调整。
- **BattleChatter 战斗喊话不在当前功能范围。**

## 日志

正常直接启动 `Bond.exe` 不写、不更新字幕日志；需要调查故障时运行 `Bond.exe --log`，在 ASI 同目录生成 `NPCSubtitles.log`、`NPCSubtitles_boot.log` 与 `NPCSubtitles_phase.log`。启动信息包括原生 LOC 扫描、字形与纹理捕获、D3D9 状态、过场消息、三行队列和白名单命中；当前白名单总量应记录为 **4**。

## 验收与回退

2026-10-11 历史 v0.1e-log6 已通过用户实机封版；v0.1e-log7 的伊斯坦布尔过场白名单台词也经用户确认能看到，用户表示其他测试无问题。log8 删除四条内置规则，log9 再删除水坝拉克两句，当前新生成的 ASI 尚未经单独 Windows 实机验收。发现 BUG 时先保存日志与场景，必要时恢复原先 v0.1e-log6 ASI；禁止同时安装两个不同版本的同名 ASI。
