## 技术等价的具体含义

| 项目 | 与输入包的关系 | 验收方式 |
|---|---|---|
| ASI 程序 | 完全相同的二进制和 C++ 源码 | 逐字节／SHA-256 |
| 五处路径及文字效果 | 同一运行时代码 | profile、签名和源码回归 |
| 86 份 LOC、7,975 条记录 | 同译文的全部键与原生正文相同 | 逐资源对照 EN／KeyTable／所有语言 |
| 非 EN 语言 | 仍复制原版七块原始字节 | 块级字节对比 |
| EN 哈希索引 | 仍使用无符号升序 | 回编后重新读取与校验 |
| 三面字库 | 同模板／同字形／2048 参数可复现相同 DAT/BPR | 与原正式字体逐字节对照 |
| 西文与图标／第三面字距 | 按原算法原样保留 | 三层 DXT1 及配对区检查 |
| 普通用户输入 | 游戏、翻译、字体改为自行提供 | 新解压模拟项目完整流程 |
| 安装物 | 相同 ASI＋同级 BSCNContents/loc 和 fonts | 整套安装目录验收 |

新工具的 LOC 直接从原 PAK 和用户 JSON 重建；不使用旧中文基线来保存历史字符串存放次序。因此 **不承诺 LOC 整文件哈希相同**，而是逐项核对原生语义、身份、排序和七种语言字节。字体不同、译文不同或自行选择大图集时，自然不能要求资源字节与作者私人方案相同。
