# 随包工具使用说明

`tools/vendor/SDL3/` 是随包固定的 SDL3 3.4.18 官方源代码，参与静态构建。
`tools/cmake/` 包含原 JoyShim 的导出表转换及工具链检查模块。
`tools/validation/` 中保留了 JoyShim 的历史源码验证器，它们的多入口发行测试不适用于本专版。
正式构建仅使用 `source/BloodStoneInput/build.bat`，输出 `release/dinput8.dll`。

`tools/验证源码.py` 可以在 Windows 或 Linux 运行，不需要 Windows SDK；检查单 DLL 专版的资源完整性、入口与 Stadia 双模式数据库记录。
`tests/standalone/test_stadia_scope.cpp` 和 `tests/icon_regression/` 为可移植的规则回归测试；这些测试不能代替 Windows 链接、真实手柄或游戏实机验收。

第三方 `tools/vendor/SDL3/` 完整保留上游文件字节及原始换行，不对它进行格式化，以保证第三方来源可追溯。
